# Pizza Kiosk

Python과 SQLite로 구현한 콘솔 기반 피자 주문 키오스크입니다. 메뉴 조회, 주문 접수, 주문 취소, 품목별 판매량 및 총매출 조회 기능을 제공합니다.

## 프로젝트 목적

간단한 키오스크의 주문 흐름을 구현하며 다음 내용을 연습하기 위한 프로젝트입니다.

- Python 모듈 분리와 함수 활용
- 클래스 기반 데이터베이스 처리
- SQLite를 이용한 영구 데이터 저장
- 사용자 입력 검증과 예외 처리
- SQL 집계 함수와 테이블 조인을 이용한 매출 계산

## 주요 기능

### 1. 메뉴 주문

- 데이터베이스에 저장된 메뉴와 가격을 표시합니다.
- 메뉴 번호와 수량을 입력받아 주문을 등록합니다.
- 주문번호와 주문 총액을 출력합니다.
- 숫자가 아닌 값, 메뉴 범위를 벗어난 값, 잘못된 수량을 검사합니다.

### 2. 주문 취소

- 주문번호를 입력받아 해당 주문을 삭제합니다.
- 존재하지 않는 주문번호를 입력하면 안내 메시지를 출력합니다.

### 3. 판매량 조회

- 주문 데이터와 메뉴 데이터를 조인합니다.
- 품목별 판매 수량과 매출을 집계합니다.
- 전체 판매금액을 계산해 표시합니다.

### 4. 자동 초기화

- 최초 실행 시 `face.db` SQLite 데이터베이스를 자동 생성합니다.
- `menu`, `orders` 테이블을 자동 생성합니다.
- 기본 피자, 사이드 메뉴 및 음료 데이터를 중복 없이 등록합니다.

## 기술 스택

| 구분 | 기술 | 용도 |
| --- | --- | --- |
| Language | Python 3 | 프로그램 로직과 콘솔 UI |
| Database | SQLite 3 | 메뉴 및 주문 데이터 저장 |
| Standard Library | `sqlite3` | SQLite 연결 및 SQL 실행 |
| Standard Library | `datetime` | 주문 날짜와 시간 기록 |
| Standard Library | `pathlib` | 실행 위치와 무관한 DB 경로 설정 |

외부 패키지를 사용하지 않으므로 별도의 `pip install` 과정이 필요하지 않습니다.

## 프로젝트 구조

```text
pizza_kiosk/
├── face_main.py   # 프로그램 진입점과 메인 메뉴 흐름
├── face_order.py  # 주문, 취소, 판매량 화면 및 입력 처리
├── face_db.py     # SQLite 연결과 CRUD 및 집계 쿼리
├── .gitignore     # DB, 캐시 등 로컬 생성 파일 제외
└── README.md      # 프로젝트 문서
```

`face.db`와 `__pycache__`는 실행 중 로컬에서 생성되며 Git에는 포함되지 않습니다.

## 실행 흐름

```text
프로그램 실행
    ↓
SQLite 데이터베이스 연결
    ↓
menu / orders 테이블 생성
    ↓
기본 메뉴 등록
    ↓
메인 메뉴 표시
    ├─ 1. 주문 → 메뉴 선택 → 수량 입력 → 주문 저장
    ├─ 2. 주문 취소 → 주문번호 입력 → 주문 삭제
    ├─ 3. 판매량 조회 → 품목별 수량·매출 집계
    └─ 4. 종료 → 데이터베이스 연결 종료
```

## 데이터베이스 설계

### `menu` 테이블

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| `menu_id` | INTEGER | 메뉴 식별자, 기본 키 |
| `menu_name` | TEXT | 메뉴명, 중복 불가 |
| `menu_price` | INTEGER | 메뉴 가격 |

### `orders` 테이블

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| `order_id` | INTEGER | 주문 식별자, 기본 키 |
| `order_date` | TEXT | 주문 날짜 |
| `order_time` | TEXT | 주문 시간 |
| `menu_id` | INTEGER | 주문 메뉴, `menu.menu_id` 참조 |
| `cnt` | INTEGER | 주문 수량 |

## 실행 방법

### 요구 사항

- Python 3.9 이상 권장
- 별도 라이브러리 설치 불필요

### 저장소 복제 및 실행

```bash
git clone https://github.com/hayoung-create/pizza_kiosk.git
cd pizza_kiosk
python face_main.py
```

Windows에서는 다음 명령도 사용할 수 있습니다.

```powershell
py .\face_main.py
```

실행하면 현재 프로젝트 폴더에 `face.db`가 생성됩니다.

## 모듈별 역할

- `face_main.py`: 데이터베이스를 초기화하고 사용자의 메뉴 선택에 따라 각 기능을 호출합니다.
- `face_order.py`: 콘솔 출력, 사용자 입력, 입력값 검증 및 주문 화면 흐름을 담당합니다.
- `face_db.py`: 데이터베이스 연결, 테이블 생성, 메뉴·주문 CRUD와 매출 집계를 담당합니다.

## 개선 아이디어

- 한 주문에 여러 메뉴를 담는 장바구니 기능
- 주문 상태(접수, 조리 중, 완료) 관리
- 관리자용 메뉴 추가·수정·삭제 기능
- 날짜별 또는 기간별 매출 통계
- GUI 또는 웹 기반 키오스크 화면
- 자동화 테스트와 타입 힌트 추가

## 데이터 관리 안내

주문 내역은 로컬의 `face.db`에 저장됩니다. 이 파일은 개인 실행 데이터가 포함될 수 있어 `.gitignore`에서 제외했습니다. 데이터베이스를 초기화하려면 프로그램을 종료한 상태에서 로컬의 `face.db`를 삭제한 후 다시 실행하면 됩니다.
